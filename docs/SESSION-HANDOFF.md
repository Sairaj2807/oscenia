## How to run the gates (and what bit us)

- **Docker Desktop must be running** (container `oscenia-erp-db`, port 5433).
- Backend tests: `cd erp-backend; .venv/Scripts/python -m pytest -q -p no:cacheprovider tests/test_x.py`. The full
  suite is run in batches of 7 files (about 25 minutes); never alongside a click-through; do not edit app code
  between batches.
- Frontend: `cd erp-frontend; npm run verify`, `npm run build`, `npm run verify:render`.
- Click-through: `node scripts/finance-live-e2e.mjs` (own backend :8771, Vite :5283, scratch DB
  `oscenia_fin_e2e`). `ONLY="<regex of step names>"` runs some steps (include "CEO signs in", it fetches the
  token). Kill stale `uvicorn app.main`, Vite and Playwright first. Low free memory (300 to 600 MB) gives
  30-second timeouts that look like code bugs; a step that advances a project to feedback must be last.
- Migration check on a scratch DB: create `oscenia_x_scratch`, `DATABASE_URL=... alembic upgrade head`,
  `alembic check` (expect only the three `ix_*_trgm` indexes as drift: intentional), `downgrade -1`, `upgrade head`,
  drop it.
- Gotchas: Postgres sequences are not rolled back with a test's transaction (assert a number's format, not its
  value); the bash tool collapses `\\n` in heredocs and chokes on some quote patterns (write patch scripts with the
  Write tool, use `chr(92)` for backslashes); many files are CRLF and UTF-8 (read/write with `newline=""` and
  `encoding="utf-8"`, never the default codec); `util.until` in the click-through returns the matching item, not the
  whole payload; Playwright refuses an `aria-disabled` click without `{ force: true }`; same-URL-with-hash does not
  reload (go through `about:blank`); `client` and `client_for` share one HTTP client in tests; an explicit constraint
  name on a model is used verbatim by Alembic's naming convention (name it the full `uq_<table>_<cols>`);
  `server_default=now()` is the transaction start (stamp ordered rows from the application clock);
  per-file ruff `F811` ignores live in `pyproject.toml` for test files that import the `world` fixture.
